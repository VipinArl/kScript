# 3. Variables and Assignment

Assigns a value or shape to a named variable.

```
identifier = expression
identifier = shapeType(params) { optionalProps }
identifier = group [ shape1(params), shape2(params) ]
```

Variables can hold numbers, booleans, strings, colors, lists, shapes, or groups.

```
x = 5
radius = x * 1.5
label = "Hello"
c = circle(8, 4.5, radius)
```
