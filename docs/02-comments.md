# 2. Comments

Single-line comments use `//`.

```
// This is a comment
c = circle(8, 4.5, 2)   // inline comment
```

Multiline comments use /\* \*/

```
/*
 This section is commented
 No statement in this section will be executed
 rect = rectangle(6, 4, 2, 3) : show()
 */

circ = circle(12, 4, 1) :show()
// This program draws only a circle

```
